# Backlit — UI/UX Redesign and New Logo — Design

**Date:** 2026-10-06
**Status:** Draft for review
**Builds on:** everything merged through PR #12. No toy behaviour changes.

## 1. Goal

Redesign the app for the Play Store in Nothing's style. It gets a new logo (the Eclipse "Diamond ring"), a home grid of live
toy cards, and one consistent swipeable page per toy. Studio, Alerts and Settings become their own pages, and a single
first-run welcome replaces the per-tab setup notices.

### Success criteria
- **Icon:** the launcher icon, the monochrome themed icon and the Play Store icon all use logo C3, matching
  `docs/superpowers/mockups/2026-10-06-logo-eclipse.html`.
- **Home** is the 2-column toy grid with live previews and statuses, plus the Studio and Alerts tool cards, as in
  `…/2026-10-06-home-layouts.html` (layout A).
- **Each toy** opens a carousel page with the shape in `…/2026-10-06-toy-page.html`. You can swipe between toys and Back
  returns to the grid. Page content never goes under the bottom action bar.
- **Every existing setting** is still reachable. No toy, Glyph output or settings data changes.
- **The 4a Pro** grid hides Music, as today.
- **Back** behaves predictably: it goes up one level, and leaves the app from Home.

### Out of scope
- New toy features.
- A light theme.
- Tablet or landscape-specific layouts (portrait phone only, as today).
- Changing toy-picker images (`ToyPreviewXml` stays).
- Store listing text and screenshots (release prep).

## 2. Logo (C3, Diamond ring)

**Geometry** (108×108 adaptive-icon viewport, centre (54, 54); safe zone r ≈ 33):
- **Ring:** 30 dots, radius 2.3, on a circle of radius 27. The dot at angle `a` (starting at 3 o'clock, going clockwise as
  in screen coordinates) has white alpha `0.12 + 0.88 · max(0, cos(a − L))³`, where `L = −π/4` (light from the upper
  right).
- **Diamond:** centred at `D = (54 + 27·cos L, 54 + 27·sin L)`. Four sparkle dots of radius 1.5 at alpha 0.7, at offsets
  (0, −6), (6, 0), (−4, 4) and (4, −4) from D. The red dot `#D71921` has radius 4 at D.
- **Background:** black.

**Assets**
- `res/drawable/ic_launcher_foreground.xml`, generated by `render/LogoXml.kt` (`LogoXml.foreground()`). It is a golden
  test like `ToyPreviewsTest`, regenerated with `UPDATE_PREVIEWS=1`.
- `res/drawable/ic_launcher_monochrome.xml`: the same geometry in white only. The ring keeps its alpha falloff, the
  sparkles keep alpha 0.7, and the red dot becomes white. The adaptive icon's `<monochrome>` points to it.
- `mipmap-anydpi/ic_launcher.xml`: background black, plus the foreground and monochrome above.
- **Play Store icon:** `docs/store/icon-512.png`, rendered from the same geometry by a JVM test helper (`LogoPng`, using
  `java.awt` in the test source set). It is written when `UPDATE_PREVIEWS=1`.
- **In-app:** `ui/components/BacklitLogo(size)` draws the same geometry on a Compose `Canvas`. `LogoGeometry` (pure,
  in `render/`) is shared by all three outputs.

## 3. Navigation

`Route` is a sealed class, saved across configuration changes:
- `Welcome`: first run only, when `!toyEverBound && !welcomeSeen` on a supported device.
- `Home`
- `Toy(id)`: the pager, opened at that toy.
- `Studio`, then `Editor(drawingId?)`
- `Alerts`
- `Settings`, then `Location`, `Privacy`, `Setup`, `About`

**Back:**
- Editor → Studio
- Location, Privacy, Setup and About → Settings
- Toy, Studio, Alerts and Settings → Home
- Home → leaves the app
- Welcome → Home (and marks it seen)

The back stack is a pure function, `Route.parent()`, so it can be unit tested.

## 4. Screens

### Home
- **Header:** `BacklitLogo(28dp)` plus "BACKLIT" (Doto 24 sp) on the left and a ⚙ (Settings) on the right.
- **Status line:** a red dot when nothing is set up, otherwise white, then
  "LIVE ON MATRIX · PHONE (3) · 5 OF 7 TOYS ON". When unsupported, it reads "THIS PHONE HAS NO GLYPH MATRIX · PREVIEW ONLY".
- **GLYPH TOYS:** a 2-column `LazyVerticalGrid` of `ToyCard`s in `ToyCatalog` order: Clock, Music, Charge, Canvas, Pet,
  Sand, Badge.
- **TOOLS:** two `ToolCard`s:
  - Studio: subtitle "N DRAWINGS"
  - Alerts: subtitle "N CONTACTS · M DEVICES"

### Toy page (`ToyPagerScreen`)
- **`HorizontalPager`** over the visible catalogue, starting at the tapped toy. The header contains:
  - ← and the label "GLYPH TOYS"
  - on the right, the toy status: "● ON GLYPH" (white) or "○ TURN ON" (grey)
- **Hero:** a live `MatrixPreview` (about 62 % of the width, centred), the name in Doto 24 sp, then `PagerDots`.
- **Status line** (labelSmall, grey), then the page content: `SettingRow`s, `ChipRow`s and `Section`s.
- **`BottomActionBar`:** fixed at the bottom on black, with a 1 dp top line and 12/16/18 dp padding. It contains:
  - **SHOW ON GLYPH:** a white pill that plays the toy's preview through `AlertsRuntime.preview`, as each tab does today.
  - **TURN ON IN GLYPH TOYS:** a red-outlined pill with a red dot, shown when the toy isn't set up. It opens Nothing's
    Glyph Toys screen directly through the existing `ToysManager.open()`, and falls back to the setup steps (`SetupScreen`)
    on systems without it.
- **Scrolling:** the content area scrolls, and its bottom padding is the bar's measured height plus 16 dp, so nothing
  sits under the bar.
- **Off-screen pages** don't run their live-preview tickers. Only the settled page animates.

### Per-toy content
Each existing tab body is split into `XxxHero(now)` (the preview grid) and `XxxContent()` (settings). The logic is reused
unchanged.

| Toy | Status line | Content |
|---|---|---|
| Clock | face name | face `ChipRow` (Analog / Day ring); second hand (Analog); time format and sun times → Location (Day ring) |
| Music | "LISTENING" / "NEEDS PERMISSION" | style chips; sensitivity chips; the permission row and explainer (existing) |
| Charge | "62 % · MOON" | style row → `OptionSheet` (built-ins plus imports with previews); done target; plug-in and done animation rows → sheets |
| Canvas | drawing name or "NO DRAWING YET" | drawing row → `OptionSheet` grid of Studio drawings; "OPEN STUDIO" row |
| Pet | "BOO IS HAPPY · MOOD 72" plus the 10-dot meter | pet row → `OptionSheet` (6 live tiles); name field; sleep hours; how mood works (expand) |
| Sand | "RUNNING · 3:12 LEFT" etc. | times `ChipRow` plus edit; when time's up chips; ring exactly on time; how it works (expand) |
| Badge | the live scroll text | message list (tap to show, ↑ ↓ EDIT) plus "+ ADD MESSAGE"; the editor opens in an `OptionSheet` |

### Studio, Alerts, Settings, About, Location
- **Studio** (drawings grid and the editor) and **Alerts** (contacts, devices, animation library) get the new header style
  (← plus a title in Doto) and the shared components. Their content and behaviour are unchanged.
- **Settings:** brightness (moved from Clock; it applies to every toy), "Glyph Toys setup" (the setup sheet), location,
  about, and "Privacy policy". That opens a `PrivacyScreen` showing the policy text bundled as `res/raw/privacy_policy.txt`, a copy of
  `docs/privacy-policy.md` kept in sync by a test. There is no published URL yet.

### Welcome (first run)
- The logo at 96 dp and BACKLIT, then one line: "Toys and tools for your Glyph Matrix."
- A 2-step card:
  1. Settings → Glyph Interface → Glyph Toys
  2. Turn on the Backlit toys you want
- Then "GET STARTED", which goes to Home and sets `welcomeSeen = true`.
- **Removed:** the per-tab "Turn on … in Glyph Toys" notices, since their job moves to the status and the
  TURN ON button.

## 5. Design system (`ui/Theme.kt`, `ui/components/`)
- **Colours:**

  | Name | Value | Use |
  |---|---|---|
  | `Black` | `#000000` | background |
  | `White` | `#FFFFFF` | text and lit dots |
  | `Dim` | `#888888` | secondary text |
  | `Line` | `#262626` | lines and borders |
  | `LedOff` | `#1C1C1C` | unlit dots |
  | `Red` | `#D71921` | "needs action" and the logo |

- **Type:**
  - `displaySmall`: Doto 24 sp
  - `titleMedium`: Doto 16 sp
  - `headlineSmall` (new): Doto 24 sp, for toy names
  - `bodyLarge` / `bodyMedium`: Space Grotesk 15 / 13 sp
  - `labelSmall`: Space Grotesk 10 sp, 2 sp tracking, uppercase by the caller
- **Shapes:** cards 14 dp; pills 50 %; rows separated by 1 dp `Line`.
- **Components:**
  - `ToyCard(grid, name, setUp, onClick)`
  - `ToolCard(icon grid, name, subtitle)`
  - `ToyHeader(onBack, setUp)`
  - `HeroPreview(grid, name)`
  - `PagerDots(count, index)`
  - `SettingRow(label, value, onClick?)` (restyled existing)
  - `ChipRow(options, selected, onSelect)`
  - `BottomActionBar(content)`
  - `OptionSheet(title, onDismiss, content)` (Material3 `ModalBottomSheet`, styled black)
  - `Section(label)`
  - `StatusPill(setUp)`
  - `BacklitLogo(size)`
- `SquareChip` and `DashedDivider` are replaced by `ChipRow`, pills and lines. `MatrixPreview` stays.

## 6. Architecture
| Unit | Responsibility |
|---|---|
| `render/LogoGeometry` | pure dot list (x, y, r, colour, alpha) for the C3 logo, in the 108 viewport |
| `render/LogoXml` | vector drawable XML for the foreground and the monochrome icon |
| `ui/home/ToyCatalog` | `ToyEntry(id, name)`, the list order, `visible(profile)` (no Music on the 4a Pro), `isSetUp(settings, id)` (the per-toy `…ToyEverBound` flags: the new `clockToyEverBound` and `musicToyEverBound`, then the existing charge, canvas, pet, sand and badge flags), and `setUpCount` |
| `ui/nav/Route` | the sealed routes, `parent()`, and saving and restoring (`Route.save()` / `Route.restore(String)`) |
| `ui/components/*` | the shared components above |
| `ui/home/HomeScreen` | the grid |
| `ui/toys/ToyPagerScreen` | the pager and page scaffold; maps `id` to the toy's Hero, Content, status line and preview id |
| `ui/toys/*Toy.kt` | one file per toy holding its Hero and Content, moved out of today's `*Screen.kt` files |
| `ui/SettingsScreen`, `ui/WelcomeScreen` | new |
| `data/Settings.welcomeSeen` | a new boolean, default false |
| `data/Settings.clockToyEverBound`, `musicToyEverBound` | new booleans, default false, set by `ClockToyService` and `MusicToyService` on bind. Today both set the shared `toyEverBound`, which keeps its meaning "any Backlit toy was used" (it drives Welcome). Migration: none. A user who used either before shows "TURN ON" until the toy binds once more |

`MainActivity` holds a `Route` (`rememberSaveable` via `Route.save/restore`) and a `BackHandler` that uses `parent()`.
